# タロットカード画像 ファイル名対応表

この README は、GitHub に保存されている数字のみの画像ファイル名と、元のタロットカード画像のファイル名・カード名を対応付けたものです。

## ファイル名の規則

- カード番号は **00〜77** の全78枚で、番号とカードの対応は固定です。
- GitHub 側の数字のみの名前は、ここでは **2桁ゼロ埋めの `<番号>.png`**（例：`00.png`、`09.png`、`22.png`）として表記しています。GitHub 側が `0.png` などゼロ埋めなしの場合は、その部分だけ読み替えてください。
- 「元のファイル名」は添付ZIP内の画像名をそのまま転記しています。
- 元ZIP内のディレクトリは `大アルカナ/` と `小アルカナ/` に分かれています。

## 管理上の注意

カード番号の割り当てを変更すると、既存の抽選処理や画像参照との整合性が失われます。ファイルを追加・差し替えする際も、原則として **番号とカード名の対応を変更しない** でください。
